# Customer Claim Screen Prototype

Audience: policyholder or customer support operator.

Purpose: capture claim details without exposing internal review logic.

## Layout

```text
┌──────────────────────────────────────────────────────────────┐
│ 보험금 청구 신청                                             │
├──────────────────────────────────────────────────────────────┤
│ Step 1. 계약 정보                                            │
│  - 상품 ID                                                   │
│  - 계약 번호                                                 │
│  - 보장기간                                                  │
├──────────────────────────────────────────────────────────────┤
│ Step 2. 사고/진료 정보                                       │
│  - 진료 유형: 통원 / 입원 / 약국                             │
│  - 급여 구분: 급여 / 비급여 / 3대 비급여                     │
│  - 진단 코드 / 치료 코드                                     │
│  - 사고일 / 진료 시작일 / 진료 종료일                        │
├──────────────────────────────────────────────────────────────┤
│ Step 3. 청구 금액 및 서류                                    │
│  - 청구 금액                                                 │
│  - 영수증 번호                                               │
│  - 제출서류 체크리스트                                       │
│    [ ] 보험금 청구서                                         │
│    [ ] 진료비 영수증                                         │
│    [ ] 진료비 세부산정내역서                                 │
│    [ ] 진단명 확인 서류                                      │
├──────────────────────────────────────────────────────────────┤
│ Step 4. 제출 전 확인                                         │
│  - 입력 누락 여부                                            │
│  - 필수 형식 오류                                            │
│  - 청구 제출                                                 │
└──────────────────────────────────────────────────────────────┘
```

## Excluded From This Screen

- 정답 라벨
- Agent reason code
- fraud 의심 여부
- 심사자 전용 risk flag
- 내부 지급 계산 상세

## UX Notes

- 사용자는 진행 단계를 명확히 볼 수 있어야 한다.
- 서류는 checkbox와 upload state로 표시한다.
- 금액은 KRW 정수 포맷으로 표시한다.
- 오류 메시지는 필드 바로 아래에 표시한다.
